개인정보처리방침

시행일: 2026년 11월 11일

요약: DNote는 개발자 서버가 없고, 광고·사용 통계를 수집하지 않습니다. 노트는 사용자의 기기와 사용자가 고른 클라우드에만 저장되며, 개발자는 사용자의 노트나 계정 정보를 볼 수 없습니다.

1. 처리하는 정보

정보어디에 두는지왜 쓰는지
노트 내용, 첨부한 사진사용자 기기, 그리고 사용자가 고른 iCloud Drive·Dropbox·Google Drive노트를 보여 주고 기기끼리 동기화하기 위해
Dropbox·Google 로그인 토큰사용자 기기의 키체인(암호화된 보관소)사용자가 고른 폴더와 동기화하기 위해
Google·Dropbox 계정 이름과 이메일사용자 기기설정 화면에 어느 계정이 연결됐는지 보여 주기 위해
앱 설정(저장 위치, 글꼴 등)사용자 기기앱 설정을 기억하기 위해

위 정보는 개발자에게 전송되지 않습니다. DNote는 광고, 사용 통계, 오류 보고, 위치 정보를 수집하지 않습니다.

2. Google 사용자 데이터

사용자가 저장 위치로 Google Drive를 고르면, DNote는 Google 로그인을 거쳐 Google Drive API 권한(https://www.googleapis.com/auth/drive)을 요청합니다.

접근하는 데이터

  • 사용자가 DNote에서 고른 폴더와 그 아래의 노트 파일(.md)과 attachments 폴더의 첨부 파일
  • 폴더를 고를 때 보여 주는 내 드라이브의 폴더 이름
  • 연결된 계정을 보여 주기 위한 Google 계정 이름과 이메일 주소

Windows의 Google Drive 앱 등 다른 기기에서 만든 노트 파일도 읽어야 하므로 Drive 전체 권한을 요청합니다. 하지만 실제로는 사용자가 고른 폴더 안의 노트·첨부 파일만 읽고 씁니다.

사용 방법

  • 고른 폴더의 노트를 기기로 내려받고, 기기에서 만들거나 고친 노트를 그 폴더에 올립니다.
  • 기기에서 지운 노트는 Google Drive의 휴지통으로 옮깁니다(완전히 지우지 않습니다).

공유와 전송

  • Google 사용자 데이터는 사용자 기기와 Google 사이에서만 오갑니다. 개발자나 다른 제3자에게 전송·판매·공유하지 않습니다.
  • 광고에 쓰지 않고, 사람이 읽지 않으며, AI·머신러닝 모델 학습에 쓰지 않습니다.

DNote가 Google API로 받은 정보를 사용하고 전송하는 방식은 Google API 서비스 사용자 데이터 정책의 제한적 사용(Limited Use) 요구사항을 따릅니다.

3. 보관과 삭제

  • 노트는 사용자가 지우기 전까지 사용자의 기기와 고른 클라우드에 남아 있습니다.
  • 설정 › 저장 위치에서 Google Drive 연결 해제를 누르면 기기에 있는 로그인 토큰과 동기화용 사본을 지우고, Google에 권한 해제를 요청합니다. Google Drive에 있는 노트 파일은 그대로 남습니다.
  • Google 계정 › 타사 앱 액세스에서도 언제든 DNote의 권한을 거둘 수 있습니다.
  • 앱을 지우면 기기에 저장된 DNote 데이터도 함께 지워집니다.

4. 다른 서비스

iCloud Drive, Dropbox, Google Drive에 저장된 노트는 각 서비스의 개인정보처리방침을 따릅니다. 알림은 기기 안에서만 만들어지며 외부 서버를 거치지 않습니다.

5. 아동

DNote는 아동을 대상으로 하지 않으며, 아동의 개인정보를 따로 수집하지 않습니다.

6. 변경과 문의

이 방침이 바뀌면 이 페이지에 새 시행일과 함께 올립니다. 문의는 GitHub 문의 게시판에 남겨 주세요.

Privacy Policy

Effective date: November 11, 2026

DNote has no servers of its own and does not collect ads data, analytics, crash reports or location. Notes and attached images are stored only on the user's device and in the cloud storage the user chooses (iCloud Drive, Dropbox or Google Drive). Sign-in tokens are kept in the device Keychain. None of this information is sent to the developer.

Google user data

When the user chooses Google Drive as the storage location, DNote requests the Google Drive API scope https://www.googleapis.com/auth/drive. The full Drive scope is needed so DNote can read note files created by other devices (for example the Google Drive app on Windows). DNote only reads and writes Markdown note files (.md) and files in the attachments folder inside the folder the user selects, lists folder names so the user can pick a folder, and reads the account name and email address to show which account is connected. Notes deleted in DNote are moved to the Google Drive trash.

Google user data is exchanged only between the user's device and Google. It is not transferred, sold or shared with the developer or any third party, is not used for advertising, is not read by humans, and is not used to train AI or machine-learning models.

DNote's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Notes remain on the device and in the chosen cloud storage until the user deletes them. Choosing "Disconnect Google Drive" in Settings deletes the tokens and the local sync copy from the device and asks Google to revoke access; note files in Google Drive are kept. Access can also be revoked at any time at myaccount.google.com/permissions. Deleting the app removes all DNote data stored on the device.
